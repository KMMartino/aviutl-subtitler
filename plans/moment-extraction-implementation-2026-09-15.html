Extract moments

Implementation completed September 15, 2026. The packaged rebuild and real-model quality evaluation have not been run.

What the feature does

  • A third top-bar button opens extraction. Existing panels, themes, resizing and run controls remain. The Local/Hosted LLM selector is now inside the subtitle screen; silence-marker settings omit LLM controls.
  • Choose one recording, optionally with a synchronized facecam, or download an archived livestream. Describe the spoken topic or visual events to retrieve.
  • An optional start/end range restricts both analysis and URL downloads. Local analysis copies are decoded for the selected range; EXO media still references the original local recording. Downloaded excerpts retain their original VOD offset.
  • The existing visual sampler runs with its defaults, alongside a complete timed transcript. Selection scans overlapping evidence windows exhaustively. It does not optimize entertainment value, repetition or final duration.
  • Matches include explanations, supporting evidence and separate Low/Medium/High confidence and relevance labels. Overlapping discoveries are merged; separated passages remain separate. Intertwined detours receive manual-cut markers.
  • Output includes JSON evidence, an HTML timestamp report and an EXO. Each excerpt’s gameplay, facecam, audio, explanation and detour objects share an AviUtl group. Excerpts appear consecutively in source order. Subtitles and in-app cut review are omitted.
  • Outputs use a fresh timestamped name beside the source. Expanding scope requires a fresh run. Earlier outputs are preserved; follow-up refinement, recovery and multiple-recording searches remain outside this iteration.

yt-dlp and spending

The application already manages a verified yt-dlp nightly executable and updater. Age warnings are now detected, including warnings split across log chunks, and offer a one-click update. Warning suppression was removed. Partial downloads use --download-sections with --force-keyframes-at-cuts; the acquired duration is checked before model processing. See the official yt-dlp documentation.

Application spending limits and their enforcement have been removed, including transcription admission, editorial ceilings and inspection budgets. Legacy monetary-limit settings are ignored or removed during configuration migration. Cost estimates, usage accounting, estimate-only transcription and request-shape validation remain. Failed extraction runs explicitly note that unfinished visual requests may not be fully accounted for.

Checkpoint compatibility and remaining validation

Extraction has its own selection contract, version 1. Removing monetary admission failures changes the earliest existing editorial execution boundary, so transcription was incremented from 14 to 15. Resuming an older editorial checkpoint invalidates transcription and its downstream boundaries.

Visual matches remain limited by the existing sampling density. Brief unsampled events can be missed. Potential variable-frame-rate sources receive a warning to inspect EXO positions. Actual relevance, exhaustiveness and cut quality still require a representative recording and an authorized hosted evaluation.
