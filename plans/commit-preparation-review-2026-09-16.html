Issue fixed during review

Moment extraction exposed the shared estimate-only setting, but a silent recording bypassed the transcription-stage check and could invoke paid visual analysis. Extraction now rejects estimate-only mode before inspecting media, preparing output or invoking hosted models. A regression test verifies that neither inspection nor visual/selection providers are called. Estimate-only extraction is explicitly unsupported; users can turn the setting off to run extraction. This execution guard does not change stored editorial evidence or selection schemas, so no additional checkpoint version change is needed.
